# Проект "Приложение для анализа банковских операций"

## Описание:

Проект "Приложение для анализа банковских операций" - учебный проект по Python-разработке,
в котором приложение будет генерировать JSON-данные для веб-страниц, формировать Excel-отчеты,
а также предоставлять другие сервисы.

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:Julia87878/Transaction-analysis-application.git
```
2. Установите зависимости:
```
poetry install
```

## Использование:

1. Функция, принимающая на вход строку с датой и временем в формате YYYY-MM-DD HH:MM:SS и
    возвращающую JSON - ответ с данными в модуле views.py.
2. Набор функций в модуле utils.py:
   Функция для считывания финансовых операций из Excel, которая возращает список транзакций.
   Функция для чтения данных из Excel, которая возращает pd.DataFrame.
   Функция, которая фильтрует транзакции по дате и возвращает список транзакций с начала месяца, на который
   выпадает входящая дата, по входящую дату.
   Функция,которая возвращает расходы и кэшбэк по каждой карте.
   Функция, которая возвращает 4 последние цифры карты в списке расходов и кэшбэка.
   Функция, которая предоставляет топ-5 транзакций по сумме платежа.
   Функция, которая возвращает курс валют.
   Функция, которая получает стоимость акций из S&P500.
3. Функция, которая принимает на вход строку для поиска и возвращающает JSON-ответ со всеми транзакциями,
    содержащими запрос в описании или категории, в модуле services.py.
4. Функция возвращает траты по заданной категории за последние три месяца (от переданной даты) в модуле reports.py.

## Тестирование:

1. При тестировании используется фреймворк Pytest.
2. Тестирование проведено с помощью фикстур и параметризации.
3. Тесты для функций используют Mock и patch.

## Декоратор:
   
  В модуле reports.py реализован декоратор для функций-отчетов, который записывает в файл результат,
    который возвращает функция, формирующая отчет.

## Логирование:

  Файлы логов записываются в папку logs.
